# Первая продажа за 20 минут

Самый короткий путь от архива до работающего магазина. Честно, без «просто
запустите и всё продаётся».

---

## Что понадобится

| Что | Где взять | Время |
|-----|-----------|-------|
| VPS (2 ГБ хватит на 25 ботов) | любой хостинг | 5 мин |
| Токен бота | [@BotFather](https://t.me/BotFather) → `/newbot` | 2 мин |
| Ваш Telegram ID | [@userinfobot](https://t.me/userinfobot) | 1 мин |
| Приём оплаты | [@CryptoBot](https://t.me/CryptoBot) → Crypto Pay → Create App | 5 мин |
| Товар для продажи | ваш | зависит |

Только последнее нельзя ускорить — это ваш товар.

## Шаг 1. Сервер

```bash
sudo bash deploy/install.sh
```

Ставит Python, nginx, файрвол, создаёт непривилегированного пользователя и
виртуальное окружение. Ботов не запускает.

## Шаг 2. Выбрать бота

```bash
python tools/fleet.py list --archetype accounts --grep steam
```

Возьмём `ru-201-steam` — магазин аккаунтов Steam.

## Шаг 3. Мастер настройки

```bash
python tools/setup.py ru-201-steam
```

Спросит токен, ваш ID и ключи оплаты — и **проверит каждый по-настоящему**:
токен через `getMe`, Crypto Pay через их API, YooKassa через `/v3/me`. Неверный
ключ вы увидите здесь, а не от недовольного покупателя.

В конце покажет, что ещё осталось сделать.

## Шаг 4. Загрузить товар

Магазин без товара показывает «нет в наличии» — это правильно, но продавать
нечем. Положите позиции в файл, по одной в строке:

```
login1@mail.com:Password123
login2@mail.com:Password456
```

```bash
python tools/fleet.py stock ru-201-steam standard accounts.txt
```

Или прямо в боте: `/stock standard`, затем отправить список сообщением.

## Шаг 5. Запуск

```bash
sudo cp bots/ru/201-steam/*.service /etc/systemd/system/
sudo systemctl enable --now botfarm-ru-201-steam
sudo journalctl -u botfarm-ru-201-steam -f
```

При старте вам в Telegram придёт отчёт: сколько товаров к продаже, какие
способы оплаты подключены и что ещё не доделано. Команда `/status` покажет то
же самое в любой момент.

## Шаг 6. Проверить как покупатель

Откройте своего бота, нажмите `/start`, купите что-нибудь. У Crypto Pay есть
тестовый режим, у YooKassa и Stripe — тестовые ключи.

Что должно произойти: каталог показывает остаток → выбор количества → оплата →
данные приходят в чат за секунду → остаток уменьшился → вам пришло уведомление
о продаже.

---

## Почему что-то может не продаваться

Бот **намеренно скрывает** товары, которые не может выдать. Это не поломка, а
защита: иначе покупатель платит и получает битую ссылку.

| Симптом | Причина | Что делать |
|---------|---------|-----------|
| «Каталог пуст» | не заменены ссылки выдачи | `config.yaml` → `catalog[].delivery` |
| «Нет в наличии» | пустой склад | `/stock SKU` или `fleet.py stock` |
| Нет кнопок оплаты | не заданы ключи | `.env`, проще всего `CRYPTOBOT_TOKEN` |
| Нет «Перевод по реквизитам» | реквизиты — заглушка | `config.yaml` → `manual_requisites` |

`/status` в боте или `python tools/fleet.py doctor <id>` перечислят всё разом.

## Что готово сразу, а что нет

Из 1000 ботов:

- **879 продают сразу** после токена, оплаты и (для магазинов) склада.
  Это все аккаунты, ключи, пополнения, услуги, консультации, мониторинги.
- **107 продают частично** — курсы и клубы, где верхний тариф с личной работой
  продаётся сразу, а тарифы с материалами ждут ваш контент.
- **14 требуют контента** до первой продажи — это магазины цифровых товаров
  (гайды, схемы). Товар там ваш, придумать его за вас нельзя.
