# BotFarm — 300 Telegram-ботов + 13 платных API

Готовый к продаже актив: **300 профессиональных Telegram-ботов** (200 для RU,
100 для EU/USA) с приёмом оплаты картами, СБП и криптой, плюс **13 микро-SaaS
API** с подписочной моделью. Всё лежит настроенным, разворачивается на VPS
одной командой и продаётся, как только появится клиент.

```
botfarm/
├── core/botcore/     движок ботов: платежи, каталог, подписки, админка
├── bots/ru/          200 ботов для российского сегмента (RUB)
├── bots/eu/          100 ботов для Европы и США (EUR)
├── saas/             13 платных API с ключами и тарифами
├── tools/            генератор и менеджер флота
├── tests/            222 теста (118 + 104 в saas)
└── docs/             передача клиенту, деплой, каталог, прайс
```

---

## Что умеет каждый бот

| | |
|---|---|
| **Оплата RU** | YooKassa (карты), СБП по QR, крипта (USDT/TON/BTC), Telegram Stars, перевод по реквизитам |
| **Оплата EU/USA** | Stripe (карты, Apple/Google Pay), крипта, Telegram Stars, банковский перевод |
| **Каталог** | 3–4 тарифа, промокоды, скидки, автовыдача после оплаты |
| **Подписки** | продление, пробный период, напоминания за 48 часов до конца |
| **Партнёрка** | реферальные ссылки, начисления 5–30 % с покупок приглашённых |
| **Админка** | выручка за сутки/неделю/месяц, воронка, рассылки, промокоды, ручное подтверждение оплат |
| **Поддержка** | тикеты с пересылкой админу, ответ командой `/reply` |
| **Надёжность** | фоновая сверка платежей, идемпотентная выдача, `/healthz` и `/metrics` |
| **Языки** | русский, английский, немецкий, испанский |

Ключевая гарантия: **за один платёж товар выдаётся ровно один раз**. Уникальный
индекс в БД по `(провайдер, ID платежа)` плюс единая точка расчёта делают
повторную выдачу невозможной — даже если вебхук придёт трижды, а фоновая
сверка сработает параллельно.

## Быстрый старт

```bash
cd botfarm
pip install -r core/requirements.txt

# Посмотреть, что есть
python tools/fleet.py list --region ru --archetype course

# Запустить одного
python tools/fleet.py activate ru-001-invest-start --token <BotFather> --admin <ваш_id>
cd bots/ru/001-invest-start && python bot.py
```

## Управление флотом

```bash
python tools/fleet.py list --tier premium --lang en   # фильтры
python tools/fleet.py show ru-019-crypto-base         # карточка бота
python tools/fleet.py activate <id> --token ... --admin ...
python tools/fleet.py doctor                          # проверка перед продажей
python tools/fleet.py status --probe                  # кто запущен и жив
python tools/fleet.py compose --region ru > compose.yml
python tools/fleet.py nginx --domain pay.example.com > nginx.conf
```

## Второй продукт: 13 платных API

В папке `saas/` — рэк из 13 независимых HTTP-API с ключами, тарифами
(free/basic/pro/scale), счётчиком запросов и приёмом оплаты через Stripe и
криптовалюту: QR-коды, OG-картинки, обработка изображений, короткие ссылки,
валидация email, 2FA, работа с текстом, dev-утилиты, конвертация данных,
цвета и WCAG, гео, НДС и IBAN, таймзоны.

Отличие от ботов — **повторяющаяся выручка**: клиент платит каждый месяц.
Подробности и цены — [saas/README.md](saas/README.md).

## Тесты

```bash
python -m pytest tests/ -q          # 118 — движок ботов и весь флот
cd saas && python -m pytest -q      # 104 — API-рэк
```

Покрыто то, что стоит денег: идемпотентность платежей, проверка подписей
вебхуков Stripe и Crypto Pay, защита от недоплаты и подмены валюты, лимиты
Telegram Stars, реферальные начисления, квоты и rate-limit API, а также
целостность всех 300 конфигураций.

## Технологии

Python 3.11+, aiogram 3, SQLAlchemy 2 (async), aiohttp, FastAPI, SQLite или
PostgreSQL. Внешних платных зависимостей нет.

## Что нужно заменить перед продажей

Боты лежат с заглушками — это осознанно: подставлять чужие ссылки и реквизиты
в 300 конфигов бессмысленно. Перед сдачей клиенту меняются:
токен и админы (`.env`), контакт поддержки, ссылки на материалы и инвайты в
каналы (`delivery`), платёжные реквизиты, отзывы. Команда
`python tools/fleet.py doctor` покажет всё незаполненное по конкретному боту.

## Лицензия

местного законодательства (регистрация бизнеса, налоги, 54-ФЗ для РФ) лежит на
владельце бота.
