# BotFarm — 1000 Telegram-ботов + 13 платных API + 12 Mini Apps

Готовый к продаже актив: **1000 профессиональных Telegram-ботов** (500 для RU,
500 для EU/USA) с приёмом оплаты картами, СБП и криптой, плюс **13 микро-SaaS
API** и **12 Telegram Mini Apps**. Всё лежит настроенным, разворачивается на
VPS одной командой и продаётся, как только появится клиент.

Основной упор — **магазины аккаунтов**: 549 ботов со складом и автовыдачей,
плюс 79 ботов пополнений и мониторингов. Всё с внутренним балансом и гарантией.

```
botfarm/
├── core/botcore/     движок: склад, платежи, баланс, подписки, админка
├── bots/ru/          500 ботов для российского сегмента (RUB)
├── bots/eu/          500 ботов для Европы и США (EUR)
├── saas/             13 платных API с ключами и тарифами
├── miniapps/         12 Mini Apps внутри Telegram
├── tools/            генератор и менеджер флота
├── tests/            336 тестов (161 + 104 saas + 71 miniapps)
└── docs/             магазины аккаунтов, передача клиенту, деплой, каталог
```

### Две гарантии, на которых всё держится

**За один платёж товар выдаётся один раз.** Уникальный индекс по
`(провайдер, ID платежа)` плюс единая точка расчёта: даже если вебхук придёт
трижды и параллельно сработает фоновая сверка, выдача одна.

**Одна единица товара уходит одному покупателю.** Списание со склада
условное — `WHERE status='available'` остаётся в самом `UPDATE`. Если кто-то
успел раньше, транзакция откатывается целиком, а не выдаёт половину заказа.
Проверено тестом: 10 одновременных покупателей на 3 аккаунта — 3 выдачи, ноль
дубликатов.

## Управление флотом

```bash
python tools/fleet.py list --archetype accounts --grep steam
python tools/fleet.py activate <id> --token ... --admin ...
python tools/fleet.py stock <id> <sku> accounts.txt   # загрузить товар
python tools/fleet.py stock-report                    # остатки по флоту
python tools/fleet.py doctor                          # проверка перед продажей
python tools/fleet.py status --probe                  # кто запущен и жив
python tools/fleet.py compose --region ru > compose.yml
python tools/fleet.py nginx --domain pay.example.com > nginx.conf
```

## Второй продукт: 13 платных API

В папке `saas/` — рэк из 13 независимых HTTP-API с ключами, тарифами
(free/basic/pro/scale), счётчиком запросов и приёмом оплаты через Stripe и
криптовалюту. Отличие от ботов — **повторяющаяся выручка**. Подробности и
цены — [saas/README.md](saas/README.md).

## Третий продукт: 12 Telegram Mini Apps

В папке `miniapps/` — приложения, которые открываются внутри Telegram по
кнопке в боте: витрина, QR-меню, запись, калькулятор сметы, квиз, лояльность,
партнёрский кабинет, трекер заказа, регистрация на событие, NPS, поддержка,
делёж счёта.

Продаются отдельно и как допродажа к боту (+50–100 % к цене). Ключевое —
подпись `initData` проверяется на сервере, поэтому подменить себя другим
пользователем нельзя. Подробности — [miniapps/README.md](miniapps/README.md).

## Тесты

```bash
python -m pytest tests/ -q            # 161 — движок и весь флот
cd saas && python -m pytest -q        # 104 — API-рэк
cd miniapps && python -m pytest -q    # 71  — Mini Apps и подпись initData
```

Покрыто то, что стоит денег: идемпотентность платежей, конкурентная выдача
со склада, защита от двойной траты баланса, подписи вебхуков Stripe и Crypto
Pay (включая подделанные и повторные), недоплата и подмена валюты, лимиты
Telegram Stars, невозможность выжечь промокод без покупки, ограничение потока
заказов, экранирование HTML в выдаче, запрет выхода за пределы `assets/`,
очистка памяти от троттлинга, проверка подписи Telegram initData от подмены
пользователя — и целостность всех 1000 конфигураций.

## Технологии

Python 3.11+, aiogram 3, SQLAlchemy 2 (async), aiohttp, FastAPI, SQLite (WAL)
или PostgreSQL. Внешних платных зависимостей нет.

## Что нужно заменить перед продажей

Боты лежат с заглушками — это осознанно: подставлять чужие ссылки и реквизиты
в 1000 конфигов бессмысленно. Перед сдачей клиенту меняются токен и админы
(`.env`), контакт поддержки, товар на складе, ссылки на материалы, платёжные
реквизиты, отзывы. Команда `python tools/fleet.py doctor` покажет незаполненное
по конкретному боту.
