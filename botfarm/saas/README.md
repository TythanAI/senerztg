# MicroSaaS Rack — 13 платных API

Второй продукт в архиве, помимо ботов. Это **13 независимых HTTP-API**, каждое
со своими ключами, тарифами, счётчиком запросов и приёмом оплаты. Продавать
можно по одному, пачкой или держать у себя и брать подписку.

Почему это отдельная от ботов история: у бота выручка разовая и зависит от
трафика владельца. У API выручка **повторяющаяся** — клиент платит каждый месяц,
пока пользуется. Один VPS тянет все 13 сразу.

## Что уже работает в каждом сервисе

- **Ключи API** — `sk_live_…`, хранятся только как SHA-256, выдаются через админ-эндпоинт
- **Тарифы** — free / basic / pro / scale с квотой в месяц и лимитом в минуту
- **Метрики использования** — заголовки `X-Quota-Used` / `X-Quota-Remaining` в каждом ответе
- **Оплата** — Stripe Checkout (карты) и Crypto Pay (USDT/TON/BTC), апгрейд плана автоматически по вебхуку
- **Защита от повторов** — оплаченный счёт повышает тариф ровно один раз
- **Документация** — Swagger UI на `/docs`, OpenAPI на `/openapi.json`, лендинг на `/`
- **Health-check** — `/healthz` для systemd, Docker и мониторинга

## Быстрый старт

```bash
pip install -r requirements.txt

export SAAS_ADMIN_TOKEN=$(openssl rand -hex 24)
python serve.py qr                    # http://localhost:8001

# Выпустить ключ:
curl -X POST "http://localhost:8001/admin/keys?plan=pro&label=first" \
  -H "X-Admin-Token: $SAAS_ADMIN_TOKEN"

# Использовать:
curl -X POST http://localhost:8001/v1/qr \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{"data":"https://example.com","size":600,"fill":"#0B5FFF"}' \
  --output qr.png
```

Все 13 сразу через Docker:

```bash
cp .env.example .env && nano .env     # обязательно SAAS_ADMIN_TOKEN
docker compose up -d
```

Как systemd на VPS:

```bash
sudo cp deploy/saas-qr.service /etc/systemd/system/
sudo systemctl enable --now saas-qr
```

## Сколько это стоит продать

Оценка по рынку готовых микро-SaaS (Acquire, Flippa, Telegram-чаты):

- **один сервис с кодом и правами** — €300–900
- **весь рэк из 13** — €3 000–6 000
- **как работающий бизнес** (есть платящие клиенты) — 24–36× месячной выручки
